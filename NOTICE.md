The interface fonts are used for the application's controls. They are **not**
substituted for fonts in your documents. The editor reuses a document font,
a labeled automatic replacement, or the specific replacement font you choose.

Downloaded Google Fonts retain each family's own OFL/Apache license; the
downloader attempts to cache that family's license next to its font data.
Uploaded and system fonts retain their original licenses. The OCR runtime
license is included in the production build at `/ocr-assets/TESSERACT-LICENSE.txt`.
Tesseract language data is obtained from the public
`https://github.com/tesseract-ocr/tessdata_fast` repository. Runtime and language
model downloads do not contain or transmit user documents.

An archive of the application's source is available through **Help → Download
source**. This archive excludes uploaded PDFs, installed dependencies, and
environment files. If you extend the project with new source directories,
update the source archive allowlist in `server/app.py`.
